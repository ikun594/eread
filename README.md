# 桌面阅读器 (EReader)

一个简单易用的 Windows 桌面文本阅读器，使用 C# WinForms 开发。

## 功能特性

- ✅ **极简界面** - 无菜单栏，纯净的阅读体验
- ✅ **悬停显示** - 鼠标悬停时才显示文本内容
- ✅ **右键菜单** - 所有功能通过右键菜单访问
- ✅ **可调整窗口大小** - 拖拽边缘自由调整窗口尺寸
- ✅ **自定义背景颜色** - 通过右键菜单设置喜欢的背景色
- ✅ **字体设置** - 自定义字体大小、样式和颜色
- ✅ **多格式支持** - 支持 .txt、.md、.epub 等文本文件
- ✅ **拖拽打开** - 直接拖拽文件到窗口即可打开
- ✅ **编码自动检测** - 自动检测文件编码，支持中文显示

## 如何运行

### 方法一：使用 Visual Studio
1. 用 Visual Studio 打开 `EReader.csproj`
2. 按 F5 运行项目

### 方法二：使用命令行
```bash
# 在项目目录下执行
dotnet run
```

### 方法三：编译发布
```bash
# 编译发布版本
dotnet publish -c Release -r win-x64 --self-contained

# 生成的可执行文件在 bin/Release/net6.0-windows/win-x64/publish/ 目录下
```

## 使用说明

1. **打开文件**：
   - 右键点击窗口 → "打开文本"
   - 直接拖拽文件到窗口

2. **查看内容**：
   - 打开文件后，将鼠标悬停在窗口上即可显示文本内容
   - 鼠标离开时内容自动隐藏

3. **设置背景颜色**：
   - 右键点击窗口 → "设置"
   - 选择喜欢的颜色

4. **调整字体**：
   - 右键点击窗口 → "字体设置"
   - 设置字体、大小和颜色

5. **调整窗口大小**：
   - 拖拽窗口边缘或角落即可调整大小
